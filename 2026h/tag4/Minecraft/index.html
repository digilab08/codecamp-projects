Was ist Minecraft?

  1. Minecraft wurde vom schwedischem entwickler Notch programmiert
  2. Die erste version von minecraft wurde in einer Woche mit java code programmiert und war 292 kilobyte gross
  3. Mnecraft ist ein vielseitiges Sand-box spiel.
  4. Minecraft gehört zu Mojang AB und hat mehrere neben spiele.
  5. Es wurde 2014 von Microsoft für 2,5 Milliarden US-Dollar aufgekauft.
  6. Das spiel wurde 425 Millionen mal verkauft und ist damit das zweit belibteste Spiel der ganzen WELT
  7. Es gab seit der ersten version 1.113 updates
  8. Minecraft hat mit 600 Millionen aktiven Spielern das spiel mit den meisten spielern weltweit
  9. Es bittet unendlich viele möglichkeit da man alles machen kann was man sich vorstellen kann sofern es mit blöcken machbar ist.
  10. Es gibt milonen von mods, die die möglihkeiten des spieles Erweitern
